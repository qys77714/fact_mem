MemoryRow 字段

字段类型说明
idstring唯一 ID（12 位 hex）
primary_textstring检索用主文本（compound golden 的「—」前半段）
cas_update_conditionstring|null变更条件 metadata（compound 的「—」后半段 + ENRICH 合并的 if-then 规则）
memory_roleprimary|evidenceprimary 参与检索；UPDATE 后旧 primary 降为 evidence
parent_primary_idstring|nullevidence 指向的新 primary（UPDATE 边）
lme_edgeUPDATE|null与 relation_decision CON 语义对齐
order_indexint全局灌库序（session asc → fact 列表序），condition 只与更小 order 比较
entitynulltext-only 模式不存储（评测侧仍用 question.entity_key）
session_indexint所属 evidence session
sourceenumgold_split | gold_if_then | plain
staleboolINVALIDATE 后 true，不参与检索
pending_rulesstring[]暂存 if-then cascade 规则，供 ENRICH / hop-2 使用

三类入库来源 → 结构映射

source识别条件生成结构
gold_split has_dependency=true 且非 if-then，文本含 — 1 个 primary + cas_update_condition
gold_if_then is_if_then=true 不新建 primary；LLM ENRICH 到同 entity 已有 primary 的 condition
plain 其余 仅 primary_text=fact_text，无 condition
